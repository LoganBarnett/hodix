Users are declaratively managed across all systems via Infrastructure as Code.

* Persons

Every entry of ~hodon.users~ is a person in the system.

Two persons, each in the groups they belong to:

#+begin_src nix :exports code
{
  hodon.users = {
    ada = {
      fullName = "Ada Lovelace";
      groups = [
        "family"
        "nextcloud-admins"
      ];
    };
    barbara = {
      fullName = "Barbara Liskov";
      groups = [ "family" ];
    };
  };
}
#+end_src

~ada~ is the login for Ada Lovelace across the hodon, and has the mail address
~ada@home.hodon.internal~.

Initial passwords are generated for every user via ~agenix-rekey~.

* Groups

You can achieve RBAC via nested membership of groups.

Three groups, one of them a role inside another:

#+begin_src nix :exports code
{
  hodon.groups = {
    family = { };
    # Nextcloud admins are also Nextcloud users.
    nextcloud-admins.groups = [ "nextcloud-users" ];
    nextcloud-users = { };
  };
}
#+end_src

With the persons in [[*Persons][Persons]], ~family~ holds ~ada~ and ~barbara~,
~nextcloud-admins~ holds ~ada~, and ~nextcloud-users~ holds ~ada~ through
~nextcloud-admins~.

* Service accounts

Generally, administrators don't need to administer Service accounts.  There is
[[*LDAP Service Accounts][LDAP Service Accounts]] for managing them, which goes into greater technical
detail.  This is because the service profiles declare what users they need, if
any.

* Under the hood

** LDAP

Hodix keeps every person, group, and service account in one LDAP directory.  It
is specifically hosted via OpenLDAP.  Declarative reconciliation happens via
[[https://github.com/LoganBarnett/nix-hapi-provider-ldap][nix-hapi LDAP provider]].

Clients reach it as ~ldap.<hodon.domain>~ over ldaps alone.  The suffix is the
domain as ~dc~ components, so ~home~ gets ~dc=home,dc=hodon,dc=internal~.
Persons sit under ~ou=users~ by ~uid~ and groups under ~ou=groups~ by ~cn~.

*** User and Group Organizations

Given this user and group arrangement:

#+begin_src nix :exports code
{
  hodon = {
    users = {
      ada = {
        fullName = "Ada Lovelace";
        groups = [
          "family"
          "nextcloud-admins"
        ];
      };
      barbara = {
        fullName = "Barbara Liskov";
        groups = [ "family" ];
      };
    };
    groups = {
      family = { };
      # Nextcloud admins are also Nextcloud users.
      nextcloud-admins.groups = [ "nextcloud-users" ];
      nextcloud-users = { };
    };
  };
}
#+end_src

~ada~ becomes ~uid=ada,ou=users,dc=home,dc=hodon,dc=internal~.

Every entry of ~hodon.groups~ is a ~groupOfNames~.  A group with no members has
no entry, since ~groupOfNames~ forbids one.  The entry appears with the first
member.

*** LDAP Service Accounts

# Implement: We aren't merging hodix configs across all hosts yet, but we have to.
Service accounts are managed in total.  Generally these are declared in the
server profile, and not in your general facts.  Service facts profiles
understand what kinds of accounts and memberships they need.

A service's account and the group it reads:

#+begin_src nix :exports code
# nixos-facts/nextcloud.nix:
{
  hodix.ldap.server = {
    accounts.nextcloud = {
      fullName = "nextcloud";
      description = "Nextcloud's bind account.";
      group = "nextcloud";
    };
    groups.nextcloud-users.description = "People who can use Nextcloud.";
  };
}
#+end_src

Passphrases are generated for service accounts automatically.  The raw
passphrase is made securely available to the service using the password.  The
passphrase is always what it is set to, but it is generated by default with high
entropy.


*** Non-Default Host

~hodon.services.ldap.host~ defaults to ~hodon.defaultHost~.

Moving it is one fact:

#+begin_src nix :exports code
{
  hodon.services.ldap.host = "shed";
}
#+end_src

*** Manually Managed

If you desire to hand-manage your LDAP directory, you can disable it thusly:

#+begin_src nix :exports code
{
  hodon.hosts.clickops-ldap = {
    managed = false;
    system = "x86_64-linux";
  };
  hodon.services.ldap = {
    enable = false;
    host = "clickops-ldap";
  };
}
#+end_src
